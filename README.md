# Dotlity

A personal productivity workspace get inspired by https://zenscape.tsuchiya-dev.com/ 

## Features

- ✅ Todo List 
- ✅ Notes
- ✅ Time and Weather
- ✅ Background Noise
- ✅ Lofi Music 
- ✅ Time & Weather 
- ✅ Pomodoro Timer 
- ✅ Light and Dark Theme
- ✅ Custom background
- ✅ Interactive widgets

## Tech Stack

### Frontend
- Javascript
- Tailwind CSS

### **Run:** Open `index.html` in a browser, or `npm run start` for a local server (port 3000).
